# MiniCato 

## About the Project

MiniCato is a web platform that connects lawyers with clients, making it easier for clients to find legal professionals and access legal services.

## Technologies Used

- **Next.js** – React framework for building web applications.
- **React** – Building interactive user interfaces.
- **TypeScript** – Type-safe JavaScript development.
- **Tailwind CSS** – Styling and responsive design.
- **CSS Modules** – Component-specific styling.
- **Zod** – Form validation.
- **REST API** – Communication with the backend.
- **Git & GitHub** – Version control and collaboration.

## Features

- User registration and login.
- Separate interfaces for clients, lawyers, and administrators.
- Lawyer and client registration forms.
- Form validation.
- Admin dashboard for managing pending accounts.
- English and Arabic language support.
